# 🏅 Olympic Games Analytics Dashboard
 
A six-page Power BI report analysing Olympic history: medals, countries, athletes, sports, host nations and participant demographics.
 
![Global Medal Overview](images/01-global-medal-overview.png)
 
## Report Pages
 
| Page | What it shows |
|------|---------------|
| **Global Medal Overview** | Total medals, countries, medals by year, top 10 countries |
| **Country Insights** | Medals, athletes and medal efficiency for any selected country |
| **Athlete Spotlight** | Top medalists, most appearances, age and gender of winners |
| **Sport & Event Analysis** | Medals and participation by sport, country dominance |
| **Host Country Analysis** | Hosting history and host vs non-host medal counts |
| **Participant Demographics** | Gender split and average age over time |
 
## Dataset
 
| File | Description |
|------|-------------|
| `Olympics_Games.csv` | Games editions and host cities |
| `Olympics_Country.csv` | Country codes and names |
| `Olympic_Games_Medal_Tally.csv` | Medals per country per edition |
| `Olympic_Athlete_Bio.csv` | Athlete biographies |
| `Olympic_Athlete_Event_Results.csv` | Athlete-level results and medals |
| `Olympic_Results.csv` | Event-level results |
 
## How to Use
 
1. Clone the repo
```bash
   git clone https://github.com/Kaushal0810/OLYMPIC-GAMES.git
```
2. Open `olympicgames_olympic_theme.pbix` in [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. If asked, point the data source to the `data/` folder, then click **Refresh**.
